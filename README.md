## 常見問題

### 美國虛擬主機需要另外買獨立 IP 嗎？

大多數情況不用。cPanel 的 AutoSSL 走 SNI 技術，免費 SSL 不需要綁獨立 IP，遠振和 GoDaddy 的免費憑證都是這個機制。真有特殊需求，遠振可以加購獨立 IP，NT$250/月（年繳 NT$2,500）。

### 免費 SSL 會不會很麻煩？

不麻煩。AutoSSL 一鍵安裝、約一分鐘生效，之後每三個月自動續約，裝完基本可以忘掉它的存在。

### 每月 4TB 流量夠用嗎？

以文字為主的部落格和企業形象站，4,000GB 多半用不完；超出可按 NT$50 設定費加每 GB NT$20 加購。做下載站或多媒體站另當別論，先算清楚再選方案。

### 遊戲私服、代理伺服器能架嗎？

不能。這類用途在共享主機的禁止清單裡，有這類需求直接看 VPS 或獨立伺服器，並確認商家條款允許。

### 完全不懂技術，管理難嗎？

共享虛擬主機就是為這種情況設計的：cPanel 中文控制台、廠商負責系統維護和 24 小時支援，你只管網站內容。VPS 預設你會自己裝環境、自己排障，兩者門檻差很多。
